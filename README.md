# Customer-Trend-Analysis-using-Python-MySQL-Power-BI

An end-to-end Data Analytics project focused on analyzing customer shopping behavior using Python, MySQL, and Power BI. The project explores customer purchasing patterns, product performance, discounts, subscriptions, shipping preferences, and customer segments to derive meaningful business insights.

🛠️ Tools & Technologies
Python – Data cleaning, preprocessing, Exploratory Data Analysis (EDA), and pattern identification
Pandas & NumPy – Data manipulation and analysis
MySQL – SQL-based analysis, aggregation, segmentation, and business queries
Power BI – Interactive dashboard development, KPI analysis, and business visualization
🔍 Project Workflow
1. Exploratory Data Analysis – Python

Performed EDA to understand the dataset, identify trends, detect patterns, and analyze customer purchasing behavior. The analysis covered areas such as:

Customer demographics
Purchase amounts and revenue
Product performance
Review ratings
Discount usage
Subscription behavior
Shipping preferences
Previous purchase behavior
Customer segmentation

2. SQL Analysis – MySQL

Created and executed MySQL queries to answer key business questions, including:

Revenue comparison across customer groups
Customers using discounts with above-average spending
Top-rated products
Average purchase amount by shipping type
Subscriber vs. non-subscriber spending
Products with the highest discount rates
Customer segmentation based on previous purchases
Top products within each category
Repeat buyer subscription behavior
Revenue contribution by age group

3. Power BI Dashboard

Developed an interactive Power BI dashboard to present the key findings in a visually intuitive format.

The dashboard focuses on:

Revenue and purchase KPIs
Customer behavior patterns
Product performance
Discount analysis
Subscription insights
Customer segmentation
Demographic analysis
Interactive filtering and visual exploration

📊 Key Analysis Areas

The project helped identify patterns in:

Customer Behavior → How purchase history, demographics, and subscriptions relate to spending.

Product Performance → Which products and categories receive higher purchases and ratings.

Discount Behavior → How frequently discounts are used across different products.

Customer Segmentation → Classification of customers into New, Returning, and Loyal segments based on previous purchases.

Revenue Patterns → Revenue contribution across customer groups and age segments.

🎯 Business Objective

The primary objective of this project is to transform raw customer shopping data into actionable business insights using a complete analytics workflow:

Raw Data → Python EDA → MySQL Analysis → Pattern Identification → Power BI Dashboard → Business Insights

This project demonstrates practical skills in data cleaning, exploratory analysis, SQL, data visualization, dashboard development, and business-oriented data interpretation.
